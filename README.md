# Buluma Enosi's Portfolio

My personal portfolio website, presenting my work as a Computer Science Engineering student focused on artificial intelligence, machine learning, full-stack development, and systems programming.

**Live site:** [bulumaenosi-portifolio.vercel.app](https://bulumaenosi-portifolio.vercel.app/)

## Highlights

- A responsive, single-page portfolio with a dark, modern interface
- Project showcase featuring the Uganda Students Electronic Voting System and other work
- Sections covering education, technical skills, leadership, current learning, and career interests
- Accessible navigation, keyboard focus states, reduced-motion support, and responsive mobile menu
- Contact form for direct visitor messages

## Built with

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Lucide icons
- AOS and Typed.js

## Featured project

### Uganda Students Electronic Voting System

A secure voting platform developed for the Ugandan Students Association in Algeria. It supports OTP authentication, voter verification, role-based administration, real-time vote counting, and transparent election management for approximately 600 students.

[View the live demo](https://usaavotingdemo.vercel.app/) · [View the source code](https://github.com/Innocebelz/usaavotingdemo)

### DevLink Chrome Extension

A Manifest V3 Chrome extension designed to improve developer productivity by providing quick access to essential development resources and everyday workflows.

**Built with:** JavaScript and Chrome Manifest V3
